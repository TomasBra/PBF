# Position Based Fluids with ScreenSpace rendering (Gaussian, Bilaterall, NarrowRange filter)
* programmed in C++ and OpenGL(GLSL)
* uses ComputeShaders for simulation
* uses FragmentShaders for multipass rendering
Overall creation time: 107 h wihtout ChatGPT and other LLMs
